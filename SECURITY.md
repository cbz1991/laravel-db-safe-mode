# Security Policy

`laravel-db-safe-mode` is a safety tool, so a bypass — a case where a guarded
write, email, notification or HTTP request still gets through while the
package is engaged — is treated as a security issue.

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub instead:

1. Go to the [Security tab](https://github.com/cbz1991/laravel-db-safe-mode/security)
   of the repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected versions and, if possible, the steps to
   reproduce it.

You'll get a reply within a few days. Once the issue is confirmed, a fix is
released as soon as possible and you'll be credited in the changelog unless
you'd rather stay anonymous.
